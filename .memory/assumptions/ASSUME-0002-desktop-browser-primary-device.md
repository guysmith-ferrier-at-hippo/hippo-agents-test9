## 1. Assumption Description
System administrators and delivery teams will access the Hippo Agent Platform administration dashboard primarily through modern desktop and tablet web browsers.

## 2. Context & Rationale
The primary personas execute administrative configurations, agent monitoring, and workflow design tasks. These complex workflows require standard screen real estate and modern web browser support (Chromium, Firefox, Safari).

## 3. Impact If Incorrect
If native mobile client applications or small-screen mobile device interfaces are strictly required, significant frontend redesign and dedicated mobile applications will be required.

## 4. Verification Path
Conduct user research interviews with delivery team members and administrators during the discovery phase.
